## Compliance rules

1. Re-check the upstream repository's license at the exact commit/version used.
2. Review transitive dependencies and bundled assets separately.
3. Preserve copyright, license, NOTICE, and attribution files when required.
4. Do not assume model weights, fonts, stock media, music, APIs, or generated assets share the software repository's license.
5. Keep optional integrations modular so a restricted project can be excluded without breaking the core skill.
6. When uncertain, do not copy the code; implement an original compatible workflow or request permission.
