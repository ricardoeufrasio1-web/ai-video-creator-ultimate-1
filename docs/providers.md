# Asset and provider strategy

The core workflow is provider-neutral. Choose tools based on quality, rights, budget, availability, language, and export requirements.

## Asset categories

- **Video:** user footage, licensed stock, generated clips, screen recordings, animation.
- **Images:** user photos, licensed stock, generated stills, diagrams, charts.
- **Voice:** user recording, licensed synthetic voice, narration recorded by a consenting speaker.
- **Audio:** licensed music, original music, sound effects, ambience, room tone.
- **Graphics:** titles, lower thirds, captions, charts, maps, icons, and brand elements.

## Provider selection checklist

- Is the tool available in the user's region and on their device?
- What are its current free-tier limits, quotas, watermarks, and commercial-use terms?
- Can the output be downloaded in the required format and resolution?
- Are voice/face cloning and reference assets authorized by the relevant person?
- Are generated outputs permitted for the intended platform and monetization?
- Can assets be exported and edited in the chosen renderer?

## Cost transparency

Separate one-time setup, subscription, per-generation credits, API usage, storage, and rendering costs. Never promise unlimited free generation. Prefer local/open-source options when the user has the hardware and expertise, while clearly noting setup and compute requirements.

## Asset manifest fields

Record: asset ID, filename, category, source/provider, scene usage, duration/dimensions, prompt or source URL, license/consent status, and continuity notes.
