# Universal visual style and genre catalog

This catalog is intentionally extensible. It is a starting taxonomy, not a claim that every style ever created can be enumerated. A brief may select one style, combine compatible styles, or define a new style preset.

## Viral editing grammar (not a guarantee of virality)
- Immediate visual or verbal hook; pattern interrupt; cold open; curiosity gap; open loop; payoff; fast/slow pacing contrast; jump cuts; punch-ins; reaction inserts; visual resets; match cuts; whip pans; speed ramps; freeze frames; split screens; picture-in-picture; callouts; kinetic captions; animated emphasis; progress bars; chapter beats; sound hits; risers; impacts; whooshes; intentional silence; beat cuts; montage escalation; reveal; before/after; loopable ending; CTA; platform-safe text zones.
- Choose techniques to serve comprehension and emotion. Avoid effects that obscure facts, accessibility, safety instructions, or product details.

## Style preset schema
Each preset should define:
- `id`, `name`, `description`, `medium` (live_action, 2d, 3d, mixed, typography, infographic);
- `visual_language`, `palette`, `lighting`, `texture`, `composition`, `camera_language`;
- `motion_language`, `editing_rhythm`, `transition_family`, `sound_language`, `caption_language`;
- `avoid`, `accessibility`, `platform_adaptations`.

A user may request "use this reference style". Describe observable attributes and create an original compatible treatment; do not copy protected characters, logos, signature artwork, or a living creator's exact style. Ask for permission/rights when reproducing user-supplied proprietary assets.

## Customization and combinations
Presets are starting points. Support style mixing with explicit weights and conflict resolution (e.g. documentary lighting + kinetic typography + restrained motion graphics). Keep a saved style bible for recurring projects: palette, typography, motion curves, transition rules, framing, texture, and sound identity.
